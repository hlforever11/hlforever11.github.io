## 1. 导入完整项目

1. 解压 `wenzheng-v21.zip`。
2. 打开微信开发者工具，用本小程序管理员/开发者微信登录。
3. 选择“导入项目”，目录选解压后包含 `project.config.json` 的 `wenzheng-v21` 文件夹；不要只选择 `miniprogram` 子目录。
4. AppID 应为 `wxf7f4471533143581`；云开发环境应为 `cloud1-d6gtx1retbc8754fa`。本包已保留原配置，无需重新注册或新建环境。

## 2. 判断是否需要部署云函数

**本次请先部署核验云函数 `verifyReference`，并建议部署文档函数 `extractDocument`，再上传客户端。** 仅上传客户端不会更新云端的核验逻辑。

### 补齐此前的云函数更新

在左侧展开 `cloudfunctions`，确认选用原云环境。依次右键下列文件夹，选择“上传并部署：云端安装依赖（不上传 node_modules）”：

| 云函数文件夹 | 本次是否必须部署 | 成功响应的build |
| --- | --- | --- |
| `verifyReference` | 是，含GB/T 7714—2025生成规则、姓名缩写容错和事实/格式分离 | `2026.10.22-gb2025-1` |
| `extractDocument` | 建议，含小体积PDF缓冲区兼容修复 | `2026.10.22-extract3` |
| `userHistory` | 本次无需更新 | `2026.10.08-visits-1000` |

等待每个函数显示部署成功，再继续下一项。顶部“上传”不会替代云函数部署。

`userHistory` 继续使用原云数据库和1000基数，保留 `newVisits`；不要手动删除数据库集合或统计文档。

若云函数部署失败，先保留当前正式客户端，记录错误提示；不要把前端上传成功当成云端更新成功。

## 3. 编译、预览与核对版本

1. 点击“编译”，页面底部只保留用途提示、隐私说明和联系邮箱；不显示版本、日期、访问量或统计状态。
2. 点击“预览”，用有权限的微信扫码，在手机上完成下列检查。
3. 如需核对云函数，在云开发控制台测试函数：

`verifyReference` 参数：

```json
{"reference":"[1] 李书宁,刘一鸣.ChatGPT类智能对话工具兴起对图书馆行业的机遇与挑战[J].图书馆论坛,2023,43(05):104-110."}
```

响应 `build` 应为 `2026.10.22-gb2025-1`。

`extractDocument` 正常导入DOCX/PDF后可检查云调用返回的 `build`；也可用空对象测试，响应可为 `ok:false`，但 `build` 应为 `2026.10.22-extract3`，这只能证明部署版本，不能证明文档解析已验证。

`userHistory` 只读测试参数：

```json
{"action":"visitRead"}
```

若使用控制台测试该函数，控制台可能没有普通微信调用的OPENID。请优先在小程序中查看计数调用结果，确认 `platform:miniprogram`、`legacyBase:1000` 和 `build:2026.10.08-visits-1000`；不要为了测试修改身份判断或统计数据库。

## 4. 真机检查清单

- 输入 `D'Ignazio, C., & Klein, L. F. (2020). Data feminism. MIT Press.`，不应因姓名缩写提示作者错误；英文国标转换默认收起。
- 输入原来的中文期刊，国标草稿应标 `GB/T 7714—2025`；不把引文页码在文章范围内的差异直接判错。
- IFLA 2019 年AI声明仍需提示年份核对：原文为2020年通过，不能因放宽格式容错而忽略事实差异。

- “填入示例”后开始核验，四条均能返回状态。
- 粘贴同一段的 `1. … 2. …` 两条完整题录，应显示2条；超过20条只核验前20条。
- 核验中点击“停止核验”，应立即恢复操作；再开始一批，旧结果不能覆盖新结果。
- 分别导入TXT、DOCX、文字版PDF；损坏文件应报错并可继续操作。
- 读取文件期间，改为手动输入或清空，旧文件不能把输入内容恢复回来。
- 开启历史记录后，核验、查看历史、载入再核验均正常。
- 页脚没有版本、日期、访问量和统计状态提示；后台访问统计继续保留。

停止核验终止的是客户端等待与本批展示；已经发到云端的请求可能仍会结束执行，其迟到结果不会回写到停止后的批次。

## 5. 上传客户端

1. 真机检查通过后，在开发者工具顶部点击“上传”。
2. 版本号填写 `1.0.21`，项目备注可填：

“按现行GB/T 7714—2025生成中文著录；英文保留不同引用规范，修复姓名和机构缩写误判，区分事实差异和格式提示。”

3. 上传成功后，登录微信公众平台 `https://mp.weixin.qq.com/`，进入本小程序的“版本管理”。
4. 在“开发版本”中找到刚上传的 `1.0.21`，可先设为体验版，复核后提交审核。
5. 审核通过后点击“发布”；至此普通用户使用的正式版才完成更新。

云函数部署会直接更新对应云端函数；客户端则需要“上传→审核→发布”。二者必须分别完成。

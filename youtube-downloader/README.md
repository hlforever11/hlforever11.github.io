# YouTube 视频下载助手

这是部署在 GitHub Pages 的静态网站。页面从 Piped 官方公开实例列表中选择可用节点，读取公开可用的视频与音频流，再由用户浏览器直接保存文件；代码不包含账号、Cookie 或密钥。

## 功能范围

- 支持公开的 YouTube 视频、Shorts 与 `youtu.be` 短链接。
- 支持带声音的视频格式、仅画面的高清格式和音频格式。
- 不支持会员、私密、付费、DRM、地区限制或正在直播的内容。
- 不建立账号，不保存解析与下载历史。
- 公开解析节点不可用时，可将链接带到 Cobalt 官方页面继续下载。
- 页脚包含邮箱，以及从本站上线时独立起算的不蒜子页面访问统计。

使用者应只下载本人创作、已获授权、公共领域或明确允许下载的内容。

# YouTube 视频下载助手

这是部署在 GitHub Pages 的前端网站，并使用独立的 Render 服务解析和生成文件。后端包含 yt-dlp、Node.js、FFmpeg 与 PO Token Provider；代码不包含账号、Cookie 或密钥。

## 功能范围

- 支持公开的 YouTube 视频、Shorts 与 `youtu.be` 短链接。
- 支持带声音的 MP4 视频格式与 MP3 音频格式。
- 不支持会员、私密、付费、DRM、地区限制或正在直播的内容。
- 不建立账号，不保存解析与下载历史。
- 下载文件仅在服务器临时生成，发送完成后自动删除。
- 页脚包含邮箱，以及使用本站专属计数页、从 0 独立起算的不蒜子持久化访问统计。

使用者应只下载本人创作、已获授权、公共领域或明确允许下载的内容。
